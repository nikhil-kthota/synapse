# SYNAPSE — AI-Powered Legacy Software Knowledge Graph Generation System

> **Transform legacy codebases into living visual knowledge graphs and queryable AI documentation.**

---

## 🚀 What is Synapse?

**Synapse** is a modern, high-performance web platform designed to analyze complex legacy codebases. By parsing Abstract Syntax Trees (AST) and mapping code dependencies, Synapse generates interactive visual knowledge graphs and intelligent documentation that allows engineering teams to understand, refactor, and navigate enterprise software in seconds.

---

## ✨ Features Accomplished

### 1. 🌌 Architectural Hero & Neural Graph Canvas
- Interactive background with animated neural synapse SVG diagrams, corner crosshair telemetry (`+`), and live status indicators (`[SYS.INTELLIGENCE: ON]`, `[GRAPH.PARSE: READY]`).
- Custom brand typography using **Guldenz** and **ClashDisplay**.

### 2. 🔍 Interactive Codebase Preview & Visualizer
- Real-time interactive dependency graph visualizer built with Canvas API and Framer Motion.
- Side-by-side file tree explorer with dark/light mode compatibility, node inspection details, and square CAD framing.

### 3. 🧩 Modular Bento Features Matrix
- CAD-inspired architectural grid sections showcasing core capabilities:
  - **AST AST-Level Parsing**
  - **Living Knowledge Graphs**
  - **AI Documentation Synthesis**
  - **Security & Dependency Mapping**

### 4. ⚙️ Step-by-Step "How It Works" Pipeline
- Detailed 4-stage architectural process flow explaining how raw source code is ingested, transformed, and queried.

### 5. 🔐 Unified Architectural Bento Auth Suite (Signup & Login)
- 100vh height-contained authentication screens.
- Connected CAD 2-column bento grid card matrix with integrated left telemetry panel (`[SYS.ENGINE]`).
- Clean 1.5px black-bordered inset input fields with interactive focus ring highlights.

### 6. 🎨 Custom Design System & Theme Engine
- Dual theme engine supporting HSL tailored palettes:
  - **Dark Mode**: Rich Deep Brown background (`#5D4439`) with silver-blue surfaces (`#C4C8D0`).
  - **Light Mode**: Warm Salmon background (`#FEC19F`) with silver surfaces.
- Square-edge architectural CAD design language with `2px` solid black borders throughout.

## 📦 Getting Started & Local Setup

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.0 or higher) installed on your machine.

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/nikhil-kthota/synapse.git
   cd synapse
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

4. **Build for Production**
   ```bash
   npm run build
   ```

5. **Preview Production Build**
   ```bash
   npm run preview
   ```
